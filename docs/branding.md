# Branding

The emerald folded C and matching editorial masthead were generated with the built-in imagegen tool on 2026-10-30. They extend the newsletter family's folded-letter style with a distinct Crypto identity.

- [Avatar master](../assets/avatar.png): preserve the native PNG as the publication logo.

## Logo prompt

```text
Use case: logo-brand.
Asset type: the square publication avatar for "This Week in Crypto", part of This Week in Newsletters.
Primary request: create one polished, distinctive capital C monogram made from a broad folded ribbon. It should form a coherent family with an existing cobalt-blue folded A monogram and an existing orange folded H monogram.
Subject: a single, unmistakable, bold uppercase C with an open aperture on the right. The ribbon has rounded outer corners and softly rounded terminals, one elegant visible fold and a deep forest-green shaded return face. The silhouette must read clearly at 32 pixels.
Style: restrained contemporary editorial brand identity, vector-like precision, subtly dimensional folded material, smooth surfaces, minimal gradients, no grain.
Color palette: luminous emerald green ribbon with a darker evergreen fold, warm near-white ivory background. The C should fill about 68 percent of the square, centered with generous consistent margins and safe for a circular avatar crop.
Text: no words or extra letters; only the C monogram.
Constraints: one finished logo on a plain square background, no presentation grid or alternatives. No coin, currency symbol, token badge, chain-link icon, market chart, arrow, decorative objects, mockup, watermark, border or heavy drop shadow. Render a high quality square brand master.
```

## Masthead prompt

The avatar master was supplied as the exact logo reference.

```text
Use case: compositing / logo-brand.
Asset type: a finished wide 3:1 README masthead for This Week in Crypto.
Use the supplied image as the exact publication logo reference. Preserve the emerald folded C monogram's silhouette, fold, colors and proportions. Build a matching wide editorial banner around it.
Composition: generous pale ivory with a very subtle light jade atmospheric background. Left half: sophisticated large dark-forest humanist serif typography on two lines, first line "This Week in", second line "Crypto". Right half: the supplied emerald folded C monogram, large and clearly legible, naturally integrated on the same pale background. A couple of restrained translucent paper/reading cards can sit behind the mark, echoing a high-quality weekly newsletter masthead. Keep abundant breathing room and never overlap the title and mark.
Small uppercase kicker at upper left: "A WEEKLY NEWSLETTER". Small uppercase kicker at upper right: "EVERY THURSDAY". Under the title, one small spaced line: "NEWS / PROJECTS / RESEARCH".
Exact publication name: "This Week in Crypto". All words must be correct and crisp. Elegant contemporary editorial identity, warm near-white background, emerald accent, dark forest text, subtle dimensional folded logo. No coins, currency logos, price charts, loud effects, watermarks or extra slogans. Make one finished 3:1 horizontal banner, not a collage or mockup.
```
